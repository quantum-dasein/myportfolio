# Индексация rodionbelousov.studio

## Что делается само

`src/pages/sitemap.xml.ts` собирает sitemap на каждой сборке — из тех же данных,
из которых строятся сами страницы. Сейчас там 37 адресов, с `xhtml:link`
альтернативами EN/DE. `src/pages/robots.txt.ts` указывает на него.

Значит: **новую страницу в sitemap вручную добавлять не нужно и заново
отправлять sitemap в Search Console тоже не нужно.** Задеплоил — Google увидит
при следующем обходе. Sitemap отправляется в GSC один раз, навсегда.

`npm run verify` не даст задеплоить состояние, в котором sitemap, canonical и
hreflang расходятся между собой.

## Что делается руками — один раз

1. **Google Search Console** → добавить `rodionbelousov.studio`, подтвердить
   домен TXT-записью, отправить `https://rodionbelousov.studio/sitemap.xml`.
2. **Bing Webmaster Tools** → импортировать сайт из Search Console.
3. **LinkedIn** → сайт в контактах и в Featured. Написание имени и город —
   ровно как на сайте: Rodion Belousov, Vienna, Austria.

Переменные `PUBLIC_GOOGLE_SITE_VERIFICATION` и `PUBLIC_BING_SITE_VERIFICATION`
поддерживаются, если подтверждать через HTML-тег, а не через DNS.

## Что делается руками — редко

**«Проверка URL» → «Запросить индексирование»** — только для новой страницы,
которую нужно в индекс сегодня, и не больше нескольких в день: у инструмента
есть суточный лимит, и он не ускоряет то, что и так в sitemap. Прогонять через
него весь сайт бессмысленно — это ровно та работа, которую sitemap уже делает.

## Что на самом деле двигает позиции

Не индексация. Все страницы этого сайта индексируются: их 37, sitemap чистый,
разметка на месте. Дальше решают две вещи:

1. **Количество страниц, отвечающих на конкретный запрос.** fidic.uz — 421
   страница и 117 статей — за 82 дня набрал 17 380 показов без рекламы. Этот
   сайт — 37 страниц. Разница в трафике объясняется этим, а не техникой.
2. **Ссылки с сайтов, которые уже ранжируются.** fidic.uz и bridgeconsult.uz
   проиндексированы и имеют трафик. Ни один из них сейчас не ссылается сюда.
